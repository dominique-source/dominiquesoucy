# DOM SOUCY MEDIA — murs signatures sportifs

Six murs approuvés, images d'origine uniquement (pas de remplacement par le mur procédural générique) :

- `basketball.webp` — **Studio média sportif Dom Soucy** (gros plan basketball)
- `athletisme.webp` — **Studio d’athlétisme cinématographique en clair-obscur**
- `hockey.webp` — **Murale studio hockey DOM SOUCY MEDIA**
- `soccer.webp` — **Studio soccer média DOM SOUCY**
- `tennis.webp` — **Studio média tennis monochrome et lime**
- `football.webp` — **Toile de fond football néon DOM SOUCY MEDIA**

Les six fichiers WebP haute qualité (1672 × 941 px) ont été déposés et vérifiés dans le dépôt.
Le ZIP de livraison fournit une copie de sauvegarde de la même structure.

Le registre `lib/analysis/studio-backdrops.ts` relie les fichiers à la galerie et
au rendu MP4. Les trois modes sont : manuel, aléatoire stable par épisode et
détection des sports par mots-clés de titre/transcription. Le décor est appliqué
en activant le mur signature et le détourage couleur dans les capsules.

**Golf :** aucun visuel officiel disponible; à ajouter uniquement après validation.
**Contrôle avant publication :** vérifier les six réponses HTTP 200 du site et
le rendu de la vidéo sur les trois angles. Les images sources appartiennent au
projet utilisateur ; ne pas les remplacer par des photos de stock.
